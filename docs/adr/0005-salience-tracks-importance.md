# Salience tracks importance, never instance count

A mark's visual weight must encode how much a thing matters to the reader,
not how many times it occurs: repeated sibling runs fold to one `×n` row
instead of dominating the diagram, badge text stays small and italic, and a
fifth context never gets a louder color than the first. Any new mark that
would make a diagram shout proportionally to list length violates this and
needs a folding/capping design first (compare: state dots cap at three, hook
strips cap at twelve).
